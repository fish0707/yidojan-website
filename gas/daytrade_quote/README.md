# 台股當沖選股 — 盤中即時報價代理 部署說明

這套工具跟飲料店（`gas/appsscript.json`）、午餐訂單（`gas/lunch_Code.gs`）**完全獨立**，
另外開一個 Apps Script 專案，不要共用同一份網址。

## 這支跟午餐訂單那套有一個關鍵不同

午餐訂單需要試算表存訂單資料，所以要先「新增試算表 → 擴充功能 → Apps Script」。

**這支不需要試算表**——它是純轉發：瀏覽器叫它、它去問證交所、把結果轉手交回來，
自己不存任何東西。可以直接建**獨立的 Apps Script 專案**，步驟更少。

## 為什麼需要這一步

`daytrade.html` 的盤中即時監控要不斷查詢股價，但瀏覽器直接呼叫證交所的即時報價 API
會被瀏覽器的 CORS 政策擋下來（跟收盤資料那批 API 遇到的問題一樣）。這支程式碼部署成
Apps Script 網頁應用程式之後，改由它在伺服器端呼叫證交所，瀏覽器只跟它講話，
就不會有 CORS 問題。

## 部署步驟

1. 前往 [script.google.com/home](https://script.google.com/home) → **新增專案**。
2. 幫專案取個名字，例如「台股當沖即時報價」，方便日後辨認。
3. 把 `gas/daytrade_quote/Code.gs` 的全部內容貼進編輯器的 `Code.gs`（覆蓋原本的內容），存檔。
4. **完成授權**：函式下拉選單選 `authorizeAndSelfTest`，按執行。
   第一次執行會跳出 Google 的同意畫面——因為是你自己貼上去的未驗證專案，
   會看到「Google 尚未驗證這個應用程式」的警告，點「**進階**」→
   「**前往〈專案名稱〉（不安全）**」即可，那個「不安全」只是指 Google 沒審核過這支腳本。
   執行完看下方的「執行紀錄」，確認兩項都是 ✅。
5. **部署為網頁應用程式**：點右上角 `部署 → 新增部署作業`，類型選「網頁應用程式」，
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
6. **複製網址**：部署後會給一段 `https://script.google.com/macros/s/AKfy.../exec`，
   把它貼進 `daytrade.js` 的 `QUOTE_GAS_URL` 常數。
7. 推上 `main`，等 GitHub Pages 部署完，回 `daytrade.html` 測試「開始盤中監控」。

> **改過程式碼要重新部署**：Apps Script 每次改完要點
> `部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署`，網址不會變。
> 若選「新增部署作業」則會產生新網址，`daytrade.js` 也要跟著換。

## 使用限制（部署前先知道）

- 證交所對這支即時報價 API 有限流，公開資訊是每 5 秒約 3 次請求。`daytrade.js`
  預設每 10 秒查一次、一次查完所有候選（一個請求帶多檔代號），正常使用不會碰到限流；
  但如果你**同時開好幾個分頁**都在監控，會疊加請求量，建議只留一個分頁在盤中監控。
- 這支 API 只回傳「當下快照」（最新成交價、當日累計最高最低），不是逐筆或現成的
  15 分鐘 K 線。`daytrade.js` 是用重複輪詢到的快照自己堆出近似的 15 分鐘蠟燭——
  兩次輪詢之間如果有一個瞬間插針又收回，可能不會被捕捉到，這跟 TradingView
  那種逐筆繪圖的精確度不是同一個等級，请把它當「輔助提醒」，不要完全依賴它扣扳機。
- 非交易時間（09:00 前、13:30 後）查得到但成交價會是空的（`price: null`），
  這是正常現象，不是故障。

## 自我檢測

隨時可以在編輯器執行 `authorizeAndSelfTest`，會實際查一次台積電（2330）的即時報價，
確認整條路（授權 → 對外連線 → 證交所回應）是通的。
